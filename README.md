# 🏥 Clínica Santa Clara

Sistema de agendamento de consultas médicas desenvolvido como projeto acadêmico de Front-End (A2).

## 📋 Sobre o projeto

O Clínica Santa Clara é uma aplicação web que simula um sistema de gerenciamento de consultas médicas. O projeto foi desenvolvido para praticar os fundamentos do desenvolvimento web, utilizando HTML, CSS e JavaScript.

## ✨ Funcionalidades

- **Agendamento de consultas:** cadastro do nome do paciente, especialidade médica e data.
- **Listagem de consultas:** visualização dos agendamentos cadastrados.
- **Filtro por status:** exibição de todas as consultas, somente as agendadas ou as concluídas.
- **Gerenciamento de status:** alteração do status de uma consulta entre agendado e concluído.
- **Acessibilidade:** controles para aumentar ou diminuir o tamanho da fonte e ativar o alto contraste.
- **Interface web:** organização visual com formulário de agendamento e lista de consultas.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🚀 Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em um navegador web.

Não é necessário instalar dependências ou configurar um servidor para executar a versão atual.

## 🎯 Objetivo acadêmico

Este projeto tem como objetivo aplicar conceitos fundamentais de desenvolvimento Front-End, manipulação do DOM com JavaScript, tratamento de eventos, organização de interfaces e recursos básicos de acessibilidade.

## ⚠️ Observação

Este é um projeto acadêmico demonstrativo. Os agendamentos são mantidos em memória durante a execução da página e não são armazenados permanentemente em um banco de dados.
